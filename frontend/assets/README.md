# 背景视频槽位

把一段**高清、循环、无水印**的背景视频放到本目录，命名任选其一即可，前端会自动探测并启用（无需改代码）：

- `bg.mp4`（推荐，H.264，720p~1080p，建议 < 8MB）
- `bg.webm`（体积更小，兼容性略低）

放好后刷新浏览器（建议 Ctrl+F5 强刷）。视频会以 **30% 不透明度** 叠加在粒子背景之上，
作为氛围层，不会抢内容。

若不放任何视频，系统自动使用内置的 **电影感柔光粒子背景**（蓝/青/紫粒子缓慢上浮），效果同样高级。
