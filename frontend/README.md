# 留学项目平台 · 全系统前端布局

以桌面“10.17项目文件个人版/frontend”的绯红、学术金、米白学院风为主体，沿用其首页、大学图片和宣传视频，按当前后端模块补齐布局。

共 69 个主要页面（另有兼容入口），覆盖公共入口、客服、客户研判、企业协作、学生服务、智能报告和平台管理。完整目录见 pages.json。

## 预览

- 首页：index.html；统一布局入口：dashboard/dashboard.html；页面总览：common/sitemap.html。
- 可直接打开HTML文件；也可在此目录运行 `python -m http.server 8765` 后访问 http://127.0.0.1:8765/ 。
- 项目后端静态服务下访问 `/static/dashboard/dashboard.html` 或 `/static/common/sitemap.html`。
- 无npm依赖，不需要构建步骤；校园图片、视频、字体回退与图标均在本地。

## 页面与交互

独立HTML页面保留完整语义内容，共享 css/workspace/layout.css 和 js/workspace/layout.js。首页使用参考目录原样式及视频素材。
提供页面导航、移动侧栏、列表搜索/状态筛选、全选、页签、表单校验、弹窗、模拟聊天、文件选择、通知已读、心情选择、待办勾选、打印报告等演示交互。

所有业务数据为合成示例，顶栏和页脚明确标记布局预览。不会调用真实业务API、Dify或数据库，不创建真实账号，不存储登录密码。当前工作重点是系统页面结构，后续可按pages.json中的后端路径逐步接入。

## 结构

- agent：公开咨询、课程、活动、报名和FAQ。
- customer：研判概览、来源、字段、结果依据、规则版本和产品目录。
- enterprise：客户档案、跟进、指令确认、日报、待办、员工组织、学生关系、教务、成绩、申请进度、审批、工单、知识、业务查询和关怀跟进。
- student：学习工作台、智能对话、课程成绩、申请、请假、提醒、工单、通知和心情记录。
- report：五类报告概览、生成、列表、正文/指标/信息与调度配置。
- common/admin：个人中心、通知、登录、账号协助、账号、角色、操作记录和平台设置。

本次仅替换或增加frontend内的页面与资源，不修改后端。此前前端文件已在工作目录备份，参考目录保持原样。
