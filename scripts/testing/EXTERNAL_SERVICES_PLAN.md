# 未配置能力的后续接入方案

本次只验证本机 MySQL 与本地业务链路，不调用外部模型、短信、邮件或支付。启动器默认屏蔽历史模型密钥，保留原 `.env` 接入项；确认可用后设置 `STUPROJECT_ENABLE_EXTERNAL=1` 才会启用。

| 能力 | 本次验证 | 后续内容 |
| --- | --- | --- |
| 客服智能对话 | 未配置时返回 503；课程、FAQ、活动报名使用真实表 | 配置 DIFY_API_BASE、DIFY_AGENT_API_KEY，发布符合客服输出契约的 Workflow；验证连续会话和失败回滚 |
| 学生智能对话、心情评估 | 无配置时预检失败，不写入“结果未知”占位；人工关怀处置已使用合成样本在真实表事务内验证 | 配置唯一 STUDENT_DIFY_KEY；验证七类意图、风险评估、来源与人工确认，不自动办理模型建议 |
| 学生请假、反馈摘要 | 原文业务完整办理，辅助摘要可显示 unavailable | 使用同一学生 Workflow 补测辅助摘要，不阻塞原文提交 |
| 企业指令、日报摘要、知识回答 | 缺少模型时明确不可用；无知识依据时返回 no_source；伪造确认凭证被拒绝 | 配置 ENTERPRISE_DIFY_API_KEY；验证 extract/query/knowledge/summary 四场景；确认签名绑定真实账号、字段、版本与有效期 |
| 自然语言业务查询 | SQL 防护、参数绑定与权限回归通过；未调用实际模型 | 配置工作流及 ENTERPRISE_READ_DB_USER/PASSWORD，只读查询角色；执行真实结果校验和跨部门拒绝测试 |
| 五类报告正文 | 收单、窗口、幂等、真实取数和失败状态验证；正文生成未通过真实模型验收 | 配置 REPORT_DIFY_API_KEY；补测五类报告对账、匿名聚合、正式发布、结果未知不重发；报告调度确认后单独启用 |
| 本地语音 | 文件/大小/依赖分支检查；不下载模型 | 安装 scripts/enterprise/requirements.txt 中可选语音依赖，准备 ASR_MODEL_PATH，本地模型仅本地加载；补测真实中文录音与资源上限 |
| 外部教务/CRM同步 | 合成批次在真实 MySQL 可回滚事务内验证；来源、学生范围和服务令牌鉴权已测；pull 未连外部源 | 配置 URL、token、STUDENT_SYNC_ENABLED、允许来源与学生范围；补测外部身份绑定、新旧快照、网络失败与重排提醒 |
| 邮件、短信、支付、自助重置密码 | 未配置，没有伪造业务成功 | 先定义供应商与业务契约，再实现通知适配器、回执/重试或支付幂等回调；账号协助页当前明确联系管理员 |

报告持久任务表 report_task 未启用，继续使用项目现有的 report_record 执行栅栏。跨进程请求回执持久化和完整任务租约仍按现有设计保留后续工作，不能将单进程幂等测试解释为已经完成跨进程恢复验收。

历史 enterprise_student 重复模块尚无实现，本次验收范围为当前已实现、已注册接口及对应页面；未交付的空模块不计为功能通过。
