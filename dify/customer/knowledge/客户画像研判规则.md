# 客户画像研判规则

本知识库用于沉淀「客户研判模块」的画像研判规则语义、字段字典与评分口径，供规则发布、
复核及后续 LLM 辅助解释参考。**规则裁决本身为确定性规则引擎执行，不依赖 LLM。**

## 一、研判规则结构（rule_content）

规则内容为 JSON 对象，发布到 `research_rule.rule_content`。结构如下：

```json
{
  "match_logic": "all",
  "conditions": [
    { "field": "education_level", "op": "in", "value": ["本科", "硕士", "博士"] },
    { "field": "work_years", "op": "ge", "value": 3 }
  ],
  "score_rules": [
    { "field": "education_level", "points": { "博士": 50, "硕士": 40, "本科": 30 } },
    { "field": "work_years", "points": { "10": 30, "5": 20, "3": 10 } }
  ],
  "score_threshold": 40
}
```

### match_logic
- `all`：所有条件同时满足（AND）。
- `any`：任一条件满足（OR）。

### conditions
逐条比对客户字段，支持运算符（op）：

| op | 含义 |
|----|------|
| eq | 等于 |
| ne | 不等于 |
| in | 取值在列表中 |
| not_in | 取值不在列表中 |
| ge / gt | 大于等于 / 大于 |
| le / lt | 小于等于 / 小于 |
| contains | 文本包含 |
| is_null / not_null | 为空 / 非空 |

### score_rules（可选）
按字段计分：字符串键为精确匹配分值；数字键为数值阈值（从大到小匹配首个满足项）。
命中依据累加为总分 score。

### score_threshold（可选）
设置后，总分不达阈值即使条件满足也判定为未命中。

## 二、客户字段字典

| 字段 | 类型 | 说明 |
|------|------|------|
| full_name | string | 客户姓名 |
| gender | string | 性别（男/女） |
| age | integer | 年龄 |
| education_level | string | 学历层次（大专/本科/硕士/博士等） |
| major | string | 专业 |
| work_years | integer | 工作年限 |
| industry | string | 所在行业 |
| position_title | string | 职位 |
| city | string | 所在城市 |
| income_level | string | 收入层级（低/中/中高/高等） |
| target_product_code | string | 意向产品编码 |

> 电话仅存加密与检索 token，邮箱仅存受控掩码，均不参与规则裁决。

## 三、内置示例规则

### PROD-A 稳健理财
- 目标画像：本科及以上、工作满 3 年。
- 条件：学历 in（本科/硕士/博士）且 工作年限 >= 3。
- 评分：学历（博士50/硕士40/本科30）+ 年限（>=10 得30 / >=5 得20 / >=3 得10），阈值 40。

### PROD-B 高端养老险
- 目标画像：35 岁以上、收入中高及以上。
- 条件：年龄 >= 35 且 收入层级 in（中高/高）。
- 评分：年龄（>=55 得50 / >=45 得40 / >=35 得30）+ 收入（高40/中高30），阈值 60。

## 四、研判流程

1. 来源登记（文本 / PDF / Excel）。
2. 解析入库：确定性解析（Excel 列映射、PDF 文本层、正则提取电话/邮箱），
   可选 Dify「客户信息抽取」工作流辅助非结构化文本语义抽取。
3. 规则裁决：加载产品生效版本，逐条件比对、评分、判定 matched。
4. 结果落库：`research_result` 记录 matched / matched_fields / unmatched_reasons / score。

## 五、口径约定

- 命中与未命中均为正常业务结果，不视为错误。
- 无有效规则、产品停用、规则格式错误时不得生成正常结论。
- 规则版本不可变，发布即停用旧生效版本。
