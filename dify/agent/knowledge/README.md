## 二、各知识库明细

### 2.1 公司信息（`公司信息.md`）

- **作用**：访客询问“你们是什么公司”“有哪些校区/部门”“怎么联系”时，基于本库作答，体现机构资质与规模。
- **内容范围**：机构概况（粤教服务简介、划转历史、使命价值观）、联系方式（地址/电话/邮箱/公众号/网址）、四大主营业务板块、国际教育四大项目、五大事业部架构。
- **源文档**：`D:\教育服务\公司信息\企业信息.docx`。

### 2.2 公司业务（`公司业务.md`）

- **作用**：访客询问具体项目（“德国双元制怎么报名”“新加坡项目多少钱”）时，介绍项目内容、优势、流程、费用与报名方式，引导进入深度咨询。
- **内容范围**：业务板块总览；中德精英人才共建计划（项目简介、三大优势、报名要求、专业类别、办理流程、项目特色、服务内容、IHK/HWK 证书、德语培训）；新加坡国际本硕升学计划（2+2、2+2+1、0.5/1+2、0.5/1+2+1、一年制专升本/本升硕、工学交替、6+6 酒店运营、9+6 航空运营各班型，含各学年学费、报名流程、入学测试、缴费账号）。
- **源文档**：`D:\教育服务\公司业务\中德精英人才共建计划.docx`、`新加坡国际本硕升学计划.docx`。

### 2.3 留学政策（`留学政策.md`）

- **作用**：访客询问政策类问题（“德国签证要什么材料”“新加坡毕业后能留下吗”）时，提供系统化政策解读，体现专业度。
- **内容范围**：德国留学政策（APS 审核、各州学费与留学预算、学生签证与居留转换、奖学金、毕业后找工作签证/机会卡/蓝卡、永居与入籍）；新加坡留学政策（SOLAR 签证与各级入学条件、学费标准与 MOE 津贴/奖学金、打工与 EP 就业准证、PR 申请、生活成本、母子陪读/教育寄宿/东盟奖学金等特殊政策）。
- **源文档**：`D:\教育服务\留学政策\德国留学政策指南.docx`、`新加坡留学政策指南.docx`。
- **注意**：政策变动频繁，文档头部的“以官网最新信息为准”提醒在回答时同样适用；建议每季度核对更新。

### 2.4 FAQ（`FAQ.md`）

- **作用**：自动识别并秒级回复申请流程、服务费用、退费政策、报名方式等高频重复性问题，降低人工客服压力。
- **内容范围**：36 条标准问答对，分三组——公司与业务概览（8 条）、新加坡国际本硕升学项目（16 条）、中德精英人才共建计划/德国双元制（12 条）。
- **源文档**：`D:\教育服务\公司信息\常见问答对.xlsx`。
- **格式约定**：一问一答独立段落、空行分隔，保证“一问一段”检索粒度最大化。

## 四、维护流程

1. **改内容**：编辑本目录对应的 `.md` 文件（源头文档在 `D:\教育服务`，改动建议同步源头）。
2. **重新上传**：在 Dify 控制台「知识库 → API 访问」创建知识库 API Key，然后执行：
   ```powershell
   python scripts/agent/reupload_dify_kb.py <知识库API密钥>
   ```
   该脚本会先删除旧文档，再按「空行分段」规则重新上传 4 个文档并更新 `dataset_ids.json`。
3. **验证**：执行 `python scripts/agent/test_dify_kb.py <知识库API密钥>`，确认 4 个库能命中预期内容。
4. **索引技术**：当前本地 Dify 未配 embedding 模型，使用**经济索引（关键词检索）**；后续配置向量模型后，可在控制台升级为「高质量」索引。
