# 客户信息研判模块

本版根据用户提供的《用户画像研判规则.docx》判断两个教育产品：新加坡国际本硕升学计划、中德精英人才共建计划。资料一次提交，分别给出两个产品的结论、条件依据、可考虑路径、缺失信息和办理阶段提示。

## 运行连接

- 前端：`http://192.168.5.13:5173/customer/customer.html`
- 客户模块独立研判服务：`http://192.168.5.13:8003`
- 原系统后端：`http://192.168.5.12:8000`

只有客户模块的文件规则研判请求发送到 8003。账号鉴权、已有来源资料和保存原始资料仍使用原后端；其他模块的连接配置未修改。本机研判服务每次向原后端校验账号权限，不另建账号，不接受客户端自报权限，不连接或写入本机业务数据库。

在项目原 Python 环境中可启动客户服务：

```powershell
$env:LOG_DIR='D:\code\StuProject\.runtime\customer-profile'
$env:CUSTOMER_AUTH_BACKEND='http://192.168.5.12:8000'
$env:CUSTOMER_FRONTEND_ORIGINS='http://192.168.5.13:5173,http://127.0.0.1:5173,http://localhost:5173'
python -m uvicorn app.services.customer.profile_app:app --host 0.0.0.0 --port 8003
```

前端按当前访问主机的 8003 端口连接客户服务。如局域网 IP 改变，启动时同步更新允许的前端来源。鉴权后端地址通过 `CUSTOMER_AUTH_BACKEND` 配置。

## 输入与结果

- 文本、TXT、MD：按单个客户提取；明确出现多位客户时要求拆分。
- PDF 简历：提取文字层；扫描件提示先 OCR。不会对空白 PDF 生成假成功。
- DOCX：支持段落和表格中的简历字段；旧版 DOC 请另存为 DOCX。
- XLSX、XLS、CSV、TSV：按表头映射，一人一行，读取所有工作表并保留工作表名称与原始行号；坏值列为未知并提示，整行无有效事实时单独报告失败。无客户表头的说明页会跳过并提示。支持模板下载。旧版 XLS 使用客户模块依赖 `xlrd`，不修改全局 Python 环境。
- 单文件上限 20 MB；文本上限 100 KiB；单表最多 200 位客户。
- 结果分为符合目标画像、暂不符合、资料不足 / 待核实。没有提供评分权重的文件不生成匹配分数或录取概率。
- 可核对并补充事实后重判两个产品；更正不覆盖原件或其他模块档案。
- 支持 CSV 导出、详情打印、手机卡片布局、只读账号限制。
- 结果详情显示已提取事实、解析冲突提示和规则版本；导出保留工作表、行号、不符合原因、待核实信息和无效客户行。提交新资料时清除上次缓存，失败后不会重新显示旧结果。
- 标签与自然语言中的否定或矛盾意愿需分别核对；“目标 / 备考 / 未取得德语 B1”不会被识别为已取得 B1。两个产品按原文件规则分别判断。

本次结果保存在当前登录标签页，不冒充已落库历史结论；切换登录会话后不复用结果。用户可单独保存本次原始资料到原后端，或导出结果。对已有来源，有原件权限时在原后端验证原件权限后读取文件重判；无原件权限时仅使用原后端返回的授权字段，缺失项保持未知。
