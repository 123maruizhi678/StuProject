# 客户研判 需求文档

## 一、项目背景与目标

### 1.1 项目背景
在客户信息收集过程中，来源形式多样，包括文本、PDF简历、Excel表格等。为提升客户筛选效率、确保后续服务与产品匹配度，需建立一套标准化的客户研判机制，对收集到的用户信息进行自动研判，判断其是否符合目标客户画像。

### 1.2 项目目标
- 基于甲方提供的《用户画像研判规则》，自动判断客户信息来源是否符合甲方公司两个产品的要求。
- 支持多种来源形式的客户信息解析，包括文本、PDF简历、Excel表格等。
- 提升客户筛选效率与准确性，降低人工研判成本。

---

## 二、需求范围

### 2.1 功能范围

| 序号 | 功能项 | 功能说明 |
|:---|:---|:---|
| 1 | 客户信息接入 | 接收来自文本、PDF简历、Excel表格等多种形式的客户信息。 |
| 2 | 信息解析与结构化 | 对不同来源的客户信息进行解析，提取关键字段。 |
| 3 | 画像研判 | 基于《用户画像研判规则》，判断客户是否符合甲方公司两个产品的要求。 |
| 4 | 研判结果输出 | 输出研判结论，供后续业务环节使用。 |

### 2.2 不在本次范围内
- 客户信息采集渠道建设
- CRM系统对接
- 客户跟进与转化流程

---

## 三、功能需求详述

### 3.1 客户信息接入
- **需求描述**：支持接收多种形式的客户信息来源。
- **来源形式**：文本、PDF简历、Excel表格等。
- **要求**：系统需具备多格式文件解析能力。

### 3.2 信息解析与结构化
- **需求描述**：对收集到的用户信息进行解析，提取研判所需关键字段。
- **要求**：针对不同来源形式，采用相应的解析方式，确保信息完整性与准确性。

### 3.3 画像研判
- **需求描述**：基于甲方提供的文件《用户画像研判规则》，判断某一客户信息来源是否符合甲方公司的两个产品的要求。
- **依据文件**：《用户画像研判规则》
- **研判对象**：甲方公司的两个产品
- **输出**：是否符合目标客户画像的结论

### 3.4 研判结果输出
- **需求描述**：将研判结论以结构化形式输出，便于后续业务系统调用或人工复核。

## 四、非功能需求

| 类别 | 需求描述 |
|:---|:---|
| 准确性 | 研判结果需严格依据《用户画像研判规则》 |
| 兼容性 | 支持文本、PDF、Excel等多种文件格式 |
| 效率 | 支持批量客户信息研判 |
| 可维护性 | 研判规则支持后续更新与调整 |
| 安全性 | 客户信息需安全存储与传输 |

---

## 五、数据需求

| 数据项 | 说明 |
|:---|:---|
| 客户信息来源 | 文本、PDF简历、Excel表格等 |
| 客户关键字段 | 研判所需的结构化信息 |
| 用户画像研判规则 | 甲方提供的规则文件 |
| 研判结果 | 是否符合目标客户画像的结论 |

---

## 六、验收标准

1. **多格式支持**：系统能正确解析文本、PDF简历、Excel表格等来源的客户信息。
2. **研判准确性**：研判结果严格依据《用户画像研判规则》，准确率不低于95%。
3. **输出规范性**：研判结论以结构化形式输出，字段完整、格式统一。
4. **规则可更新**：支持《用户画像研判规则》的后续更新与维护。
