# 学生智能助手 需求文档

## 一、项目背景与目标

### 1.1 项目背景
为提升学生服务体验，缓解学生在海外留学过程中的行政、心理、学业、生活等多方面压力，拟建设一套面向学生的智能助手。该助手需覆盖行政服务、心理关怀、售后反馈、学业考务、进度追踪、生活支持及增值转化等场景，实现学生服务的高效闭环与主动关怀。

### 1.2 项目目标
- 支持学生在线提交请假申请，并实现移动端在线审批闭环。
- 提供日常情绪闲聊与疏导，实时监测心理状态，触发高危预警。
- 支持在线投诉与建议提交，自动生成工单并同步处理结果。
- 对接教务数据，支持学业考务查询与智能提醒。
- 打通内部CRM或申请系统，支持留学业务进度自助查询。
- 内置海外生活知识库，提供生活常识问答。
- 智能识别升学意向，推送学历提升项目，挖掘二次转化价值。

## 二、需求范围

### 2.1 功能范围

| 序号 | 功能项 | 功能说明 |
|:---|:---|:---|
| 1 | 行政服务 | 支持学生在线提交请假申请，系统自动推送至班主任，并支持通过企业智能助手实现移动端在线审批，形成完整的请假闭环。 |
| 2 | 心理关怀 | 提供日常情绪闲聊与疏导，AI实时监测学生心理状态。一旦识别出高危风险，立即触发预警并记录原因，辅助老师通过企业助手快速介入干预。 |
| 3 | 售后反馈 | 支持在线投诉与建议提交，自动生成工单存入反馈表。老师跟进处理完毕后，系统自动向学生同步“您的xxx投诉已解决”的反馈通知。 |
| 4 | 学业考务 | 对接教务数据，支持学生随时查询论文DDL、考试时间等关键节点，并可设置考前或截止前的智能提醒，规避学业风险。 |
| 5 | 进度追踪 | 打通内部CRM或申请系统，学生可随时自助查询文书审核、院校申请及签证办理等留学业务的具体进度，缓解等待焦虑。 |
| 6 | 生活支持 | 内置海外生活知识库，提供当地医疗、交通、紧急求助等生活常识问答，做学生身边的本地百事通。 |
| 7 | 增值转化 | 智能识别学生的升学意向（如硕博咨询），适时推送机构最新的学历提升项目，挖掘存量客户的二次转化价值。 |

### 2.2 不在本次范围内
- 教务系统本身的建设
- CRM系统本身的建设
- 支付与合同签署功能

## 三、功能需求详述

### 3.1 核心数据表设计
需新建四张关键数据表：

| 数据表 | 说明 |
|:---|:---|
| 学生行政服务表 | 记录请假、考务等申请单、审批状态及教务关联数据。 |
| 心理健康画像表 | 存储学生的情绪标签、分值及历史波动数据。 |
| 心理预警表 | 记录高危预警触发原因、风险等级及老师跟进状态。 |
| 售后反馈工单表 | 管理投诉内容、处理进度及最终解决方案。 |

### 3.2 业务逻辑开发

#### 3.2.1 多意图路由
- **需求描述**：接入模型，精准识别并分流7大业务场景。

#### 3.2.2 审批闭环
- **需求描述**：打通“学生提交-写入数据表-推送班主任-在线审批-回调通知”的全链路。

#### 3.2.3 系统对接
- **需求描述**：开发API接口，实时拉取教务系统的DDL数据与CRM系统的申请进度。

#### 3.2.4 知识库搭建
- **需求描述**：导入海外生活指南与升学项目资料，实现RAG精准检索。

### 3.3 AI能力配置

#### 3.3.1 风险识别
- **需求描述**：编写专属Prompt，实时监测闲聊情绪，触发高危预警并自动写入预警表。

#### 3.3.2 智能摘要
- **需求描述**：自动提炼学生长篇投诉为工单摘要。

#### 3.3.3 营销生成
- **需求描述**：根据学生画像，自动生成个性化的学历提升推荐话术。

## 六、验收标准

1. **行政服务**：学生可在线提交请假申请，审批闭环完整。
2. **心理关怀**：可实时监测学生心理状态，高危风险触发预警并记录原因。
3. **售后反馈**：可在线提交投诉与建议，自动生成工单并同步处理结果。
4. **学业考务**：可查询论文DDL、考试时间，并设置智能提醒。
5. **进度追踪**：可自助查询文书审核、院校申请及签证办理进度。
6. **生活支持**：可查询海外生活常识，RAG检索准确。
7. **增值转化**：可识别升学意向并推送学历提升项目。
8. **多意图路由**：7大业务场景识别准确率不低于90%。
9. **风险识别**：高危预警触发及时，写入预警表准确。
10. **智能摘要**：投诉摘要提炼准确、简洁。
11. **营销生成**：推荐话术个性化、符合学生画像。
