# API接口文档

一、通用说明

1.1 接口风格
RESTful API

1.2 基础路径
/api/v1

1.3 通用响应格式
```json
{
  "code": 0,
  "message": "success",
  "data": {}
}

1.4 通用状态码
状态码	说明
0	成功
400	请求参数错误
401	未授权
500	服务器内部错误

二、客户研判模块接口
2.1 提交客户信息研判
接口：POST /api/v1/customer/judge

请求参数：
json
{
  "source_type": "text/pdf/excel",
  "source_content": "客户信息内容"
}

响应：
json
{
  "code": 0,
  "message": "success",
  "data": {
    "judgement_id": 1,
    "is_match": true,
    "product_code": "P001",
    "judgement_reason": "符合目标客户画像"
  }
}

2.2 查询研判结果
接口：GET /api/v1/customer/judge/{judgement_id}

响应：
json
{
  "code": 0,
  "message": "success",
  "data": {
    "judgement_id": 1,
    "customer_info_id": 1,
    "is_match": true,
    "judgement_reason": "符合目标客户画像"
  }
}

三、客服Agent模块接口
3.1 客服对话
接口：POST /api/v1/agent/chat

请求参数：
json
{
  "user_id": "U001",
  "message": "你们公司有哪些留学项目？"
}
响应：
json
{
  "code": 0,
  "message": "success",
  "data": {
    "intent": "business_query",
    "reply": "我们公司提供留学申请、背景提升、语言培训等服务..."
  }
}

3.2 查询活动列表

响应：

{
  "code": 0,
  "message": "success",

四、企业智能助手模块接口

  },

  "data": {
    "customer_id": 1
