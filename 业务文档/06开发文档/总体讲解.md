
采用 **前端 + FastAPI 后端 + 本地 Dify + 本地 MySQL** 的四层架构。
前端用dify中的nginx容器，然后调用FastAPI后端接口
FastAPI 后端去调用智能体的apiKEY
本地Dify写智能体
MySQL建表

结构
app/
├── main.py                     # 入口，FastAPI 初始化 + 路由注册
├── config.py                   # 环境变量/配置管理
├── database.py                 # MySQL 异步引擎 + 会话管理
├── models/                     # SQLAlchemy ORM 模型
├── schemas/                    # Pydantic 请求/响应模型
├── api/                        # 路由层
├── services/                   # 业务逻辑层
└── tasks/                      # 定时任务
├── logs/                       # 新增：日志输出目录
    文件名：年月日.log
├── core/                       # 新增：核心基础设施
