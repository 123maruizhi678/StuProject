# 项目开发文档

> 本文档整合了项目总需求、各模块需求、开发设计、数据库设计及接口设计，作为项目开发的完整参考文档。

---

## 一、项目概述

### 1.1 项目背景

本项目旨在建设一套面向留学机构的智能化服务系统，涵盖客户研判、智能客服、企业内部助手、学生服务及智能报告五大核心模块，通过AI能力（NLP意图识别、RAG检索增强生成、NL2SQL、语音识别等）提升机构在客户获取、服务交付、内部运营及学生关怀等方面的效率与质量。

### 1.2 项目目标

- 建立标准化的客户研判机制，自动判断客户是否符合目标画像

- 实现7×24小时智能客服，覆盖7大业务场景

- 提升企业内部运营效率，降低事务性工作成本

- 提供全方位学生服务，增强客户粘性与二次转化

- 通过智能报告为管理层提供数据驱动的决策支持

### 1.3 需求总览

本项目包含以下五大需求模块：

| 序号 | 需求模块 | 核心描述 |
|:---|:---|:---|
| 1 | 客户研判 | 对收集到的用户信息进行研判，判断是否符合目标客户画像 |
| 2 | 客服Agent | 智能客服，覆盖公司咨询、业务查询、政策查询、课程推荐、活动报名、FAQ解答、闲聊互动 |
| 3 | 企业智能助手 | 面向企业员工，覆盖客户管理、日报、组织架构、新人指引、学生业务综管 |
| 4 | 学生智能助手 | 面向学生，覆盖行政服务、心理关怀、售后反馈、学业考务、进度追踪、生活支持、增值转化 |
| 5 | 智能报告 | 全域客户经营分析、员工日报汇总、学生心理健康周报、投诉处理周报 |

### 3.1 客户研判模块

# 客户研判 需求文档

## 一、项目背景与目标

### 1.1 项目背景
在客户信息收集过程中，来源形式多样，包括文本、PDF简历、Excel表格等。为提升客户筛选效率、确保后续服务与产品匹配度，需建立一套标准化的客户研判机制，对收集到的用户信息进行自动研判，判断其是否符合目标客户画像。

### 1.2 项目目标
- 基于甲方提供的《用户画像研判规则》，自动判断客户信息来源是否符合甲方公司两个产品的要求。
- 支持多种来源形式的客户信息解析，包括文本、PDF简历、Excel表格等。
- 提升客户筛选效率与准确性，降低人工研判成本。

## 二、需求范围

### 2.1 功能范围

## 三、功能需求详述

### 3.1 客户信息接入
- **需求描述**：支持接收多种形式的客户信息来源。
- **来源形式**：文本、PDF简历、Excel表格等。
- **要求**：系统需具备多格式文件解析能力。

### 3.2 信息解析与结构化
- **需求描述**：对收集到的用户信息进行解析，提取研判所需关键字段。
- **要求**：针对不同来源形式，采用相应的解析方式，确保信息完整性与准确性。

### 3.3 画像研判

- **依据文件**：《用户画像研判规则》
- **研判对象**：甲方公司的两个产品
- **输出**：是否符合目标客户画像的结论

### 3.4 研判结果输出
- **需求描述**：将研判结论以结构化形式输出，便于后续业务系统调用或人工复核。

### 3.2 客服Agent模块

# 客服Agent 需求文档

## 一、项目背景与目标

### 1.1 项目背景
为提升机构客户服务效率与质量，降低人工客服接待压力，拟建设一套面向访客与潜在客户的智能客服Agent。该Agent需覆盖公司信息咨询、业务查询、留学政策解读、课程项目推荐、活动报名、常见问题解答及日常闲聊等场景，建立客户对机构的第一层信任感，并有效沉淀私域流量。

### 1.2 项目目标
- 实现7×24小时智能客户服务，随时响应访客咨询。
- 精准匹配客户需求与服务项目，引导客户进入深度咨询环节。
- 依托实时更新的全球留学政策知识库，体现机构专业度。
- 支持活动预约与报名，有效沉淀私域流量。
- 自动识别并秒级回复高频重复性问题，大幅降低人工客服接待压力。
- 提供拟人化友好交互体验，提升潜在客户留存率。

---

## 二、需求范围

### 2.1 功能范围
本需求文档涵盖客服Agent的以下七大核心业务场景：

| 序号 | 业务场景 | 功能说明 |
|:---|:---|:---|
| 1 | 公司信息咨询 | 随时解答访客关于机构品牌背景、发展历程、成功案例及校区分布等基础信息，建立客户对机构的第一层信任感。 |
| 2 | 公司业务查询 | 精准回应客户关于留学申请、背景提升、语言培训等核心业务板块的咨询，快速匹配客户需求与服务项目。 |
| 3 | 海外留学政策查询 | 依托实时更新的全球留学政策知识库，为客户解读各国签证要求、院校申请门槛及最新的移民就业政策，体现机构的专业度。 |
| 4 | 课程与项目推荐 | 基于客户的学历背景与留学意向，智能推荐匹配的留学方案、语言课程或背景提升项目，引导客户进入深度咨询环节。 |
| 5 | 活动与讲座报名 | 支持客户查询近期的线上/线下留学分享会、招生官见面会，并直接完成活动预约与报名，有效沉淀私域流量。 |
| 6 | 常见问题自助解答 | 自动识别并秒级回复关于申请流程、服务费用、退费政策等高频重复性问题，大幅降低人工客服的接待压力。 |
| 7 | 日常闲聊互动 | 提供拟人化的友好交互体验，在客户等待或无明确诉求时进行情感维系，保持对话热度，提升潜在客户的留存率。 |

### 2.2 不在本次范围内
- 人工客服工单系统
- CRM客户管理系统
- 支付与合同签署功能

## 三、功能需求详述

### 3.1 知识库与数据源搭建

#### 3.1.1 基础文件解析
- **需求描述**：接入并处理甲方提供的《公司信息》、《公司业务》和《留学政策》三份核心文档。
- **处理方式**：对文件进行结构化切片与向量化存储，以便Agent能够精准检索到品牌背景、业务板块及各国签证门槛等关键信息。
- **输入**：《公司信息》、《公司业务》、《留学政策》三份核心文档。
- **输出**：结构化切片数据、向量化存储索引。

#### 3.1.2 常见问题库（FAQ）
- **需求描述**：基于历史高频咨询，梳理申请流程、服务费用、退费政策等标准问答对。
- **目标**：提升秒级回复的准确率。
- **数据来源**：历史高频咨询记录。

#### 3.1.3 活动与课程数据库
- **需求描述**：建立结构化的课程项目表与近期讲座活动表。
- **字段要求**：包含时间、地点、报名方式等字段。
- **目标**：支撑精准推荐与报名功能。

### 3.2 AI能力与提示词配置

#### 3.2.1 多意图识别
- **需求描述**：接入NLP模型，精准区分客户咨询的7大场景（如业务查询、政策咨询、闲聊等）。
- **目标**：确保对话路由准确。

#### 3.2.2 年轻化闲聊人设
- **需求描述**：针对“日常闲聊”意图，专门设计亲切、可爱且符合年轻人语境的系统提示词（Prompt）。
- **要求**：AI在互动中适度使用网络热梗或温暖的情感表达，打破传统机器人的生硬感，拉近与留学生的距离。

#### 3.2.3 个性化推荐逻辑
- **需求描述**：配置条件判断逻辑，让Agent能根据客户提供的学历背景和意向国家，自动匹配并推送最合适的课程或留学方案。

### 3.3 核心交互与业务闭环

#### 3.3.1 智能检索与问答
- **需求描述**：实现基于RAG（检索增强生成）的精准问答。
- **要求**：确保Agent在回答公司背景与留学政策时严格基于知识库，避免产生幻觉。

#### 3.3.2 活动报名闭环
- **需求描述**：设计活动表，开发活动查询与报名接口。
- **要求**：支持客户在对话中直接完成留学分享会或见面会的预约，并将报名信息自动录入后台系统。

### 3.3 企业智能助手模块

# 企业智能助手 需求文档

## 一、项目背景与目标

### 1.1 项目背景
为提升企业内部运营效率，降低员工手动填单、日报汇报、信息查询等事务性工作的时间成本，拟建设一套面向企业员工的智能助手。该助手需覆盖意向客户管理、日报口述与查阅、组织架构查询、新人入职指引及学生业务综管等场景，实现企业内部信息的高效流转与业务闭环。

### 1.2 项目目标
- 支持员工通过语音或文字快速录入、查询、更新意向客户信息。
- 支持口述日报并自动转化为结构化文本，赋能管理层快速查阅。
- 提供组织架构查询与新人入职指引，降低培训成本。
- 一站式处理学生端核心业务，实现教务与售后的高效闭环。
- 通过NL2SQL、主动待办推送、指令式业务处理等AI能力，提升交互效率。

## 一、项目背景与目标

### 1.1 项目背景

### 3.5 智能报告模块

## 需求项：智能报告

**详细描述：**
1. 全域客户经营分析报告
2. 员工日报汇总报告（日）
3. 员工日报汇总报告（周）
4. 学生心理健康周报
5. 投诉处理周报

**需求详细拆解：**
全域客户经营分析报告，需全面覆盖意向、成交及流失三大核心客群。针对意向客户，重点统计新增数量及同环比趋势，并通过特征聚类精准提炼共性画像；针对成交客户，深度复盘其转化路径与高价值特征；针对流失客户，智能归因并预警流失风险。最终通过多维度的AI洞察，为业务团队提供从精准获客、高效转化到流失挽回的全链路决策支持。
员工日报智能汇总报告，旨在通过日、周等多维时间粒度，对全员提交的工作内容进行自动化梳理与提炼。系统利用AI智能提取日报中的核心进展、关键产出及潜在风险，将碎片化的日常记录转化为结构化的工作简报。这不仅大幅降低了领导层的阅读成本，更能帮助管理层快速、精准地感知团队整体工作进度与项目健康度，从而为资源协调与战略决策提供高效、透明的数据支撑。
学生心理健康周报，旨在为海外学子提供全方位的心理状态监测与关怀支持。报告基于留学生的日常情绪打卡、学业压力反馈及跨文化适应情况，利用AI智能汇总本周整体心理态势，精准识别存在孤独感、学业焦虑或文化冲突等潜在风险的学生群体。同时，系统会结合留学周期的特殊节点（如考试周、假期），生成情绪波动趋势分析，并智能推荐个性化的心理疏导方案与社群支持建议。这不仅帮助机构顾问及时掌握学生的海外生活状态，更能通过主动关怀增强客户粘性，全方位守护留学生在异国他乡的身心健康。
投诉处理周报，旨在通过全流程的数据追踪，提升海外留学服务的售后质量与响应效率。报告不仅实时汇总本周的投诉总量及其同环比变化，还会利用AI对投诉内容进行智能分类（如签证办理、院校申请、生活服务等）。系统会重点追踪每一笔投诉的跟进状态、处理时效及最终满意度，自动识别长期未决的疑难案件并触发预警。通过可视化的处理进度与归因分析，帮助管理层快速发现服务流程中的薄弱环节，确保学生的每一条反馈都能得到及时、妥善的解决，从而持续提升机构口碑与客户信任度。
