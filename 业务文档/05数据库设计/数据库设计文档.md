# 数据库设计文档

## 一、总体说明

本系统数据库分为五大模块：
1. 客户研判模块
2. 客服Agent模块
3. 企业智能助手模块
4. 学生智能助手模块
5. 智能报告模块

数据库类型：关系型数据库 + 向量数据库
- 关系型数据库：存储业务数据表
- 向量数据库：存储知识库切片向量

---

## 七、数据库设计说明

| 项目 | 说明 |
|:---|:---|
| 数据库类型 | 关系型数据库 + 向量数据库 |
| 字符集 | UTF-8 |
| 主键策略 | 自增BIGINT |
| 时间字段 | DATETIME |
| JSON字段 | 用于存储结构化扩展数据 |
| 向量字段 | 用于RAG检索 |
