# 学生智能助手数据库设计 V3

业务表共六张：mental_health_profile、mental_warning、student_academic_event、student_academic_reminder、student_application_progress五张专属表，以及公共student_leave_request。

字段字典、与组长结构的对照及初始化说明见[学生建表方案](../../scripts/sql/学生智能助手/学生智能助手_建表方案.md)。SQL由scripts/export_student_artifacts.py导出，公共请假DDL直接取企业版本，不维护另一份请假事实源。

学生主键关联student_profile.student_id；老师关联employee.employee_id。预警(profile_id,student_id)及提醒(academic_event_id,student_id)使用组合外键防跨学生关联。工单、处理记录、通知、审计与身份归属继续复用公共表。

专属表DATETIME(6)，公共请假等企业表DATETIME(3)，时间为UTC；ID为有符号BIGINT，MySQL8.0.16+、InnoDB、utf8mb4。预警物理版本列version，API统一返回row_version。提醒无新增版本列，微秒updated_at区分设置代次。

初始化脚本仅建缺失六表，不删除数据、不自动改已有结构。Web启动不建表。开发实例的最小共享前置表只供本地联调，生产迁移仍由公共表负责人维护。旧V1独立身份/请假/工单/通知草案不再执行。
