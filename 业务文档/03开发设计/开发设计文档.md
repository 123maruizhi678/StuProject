# 开发设计文档

## 一、总体架构设计

### 1.1 系统架构

本系统由五大核心模块组成：

1. 客户研判模块
2. 客服Agent模块
3. 企业智能助手模块
4. 学生智能助手模块
5. 智能报告模块

各模块共享底层能力层，包括：NLP意图识别、RAG检索增强生成、NL2SQL、语音识别、知识库管理、数据表CRUD接口。

### 1.2 技术架构分层

| 层级    | 说明                               |
| :---- | :------------------------------- |
| 接入层   | 客服Agent、企业智能助手、学生智能助手、智能报告入口     |
| 应用层   | 客户研判、客服Agent、企业智能助手、学生智能助手、智能报告  |
| 能力层   | NLP意图识别、RAG、NL2SQL、语音识别、Prompt管理 |
| 数据层   | 业务数据表、知识库向量存储、FAQ库、活动课程库         |
| 基础设施层 | 数据库、向量数据库、文件存储、定时任务              |

---

## 二、客户研判模块开发设计

### 2.1 模块职责

- 接收多格式客户信息（文本、PDF简历、Excel表格）
- 解析并结构化客户信息
- 基于《用户画像研判规则》进行画像研判
- 输出研判结论

### 2.2 核心流程

1. 客户信息接入 → 2. 格式识别 → 3. 内容解析 → 4. 关键字段提取 → 5. 规则匹配 → 6. 研判结果输出

### 2.3 关键技术点

- 多格式文件解析：PDF解析、Excel解析、文本解析
- 规则引擎：基于《用户画像研判规则》实现可配置规则匹配
- 研判结果结构化输出

### 2.4 依赖关系

- 依赖《用户画像研判规则》文件
- 无前置模块依赖

---

## 三、客服Agent模块开发设计

### 3.1 模块职责

- 公司信息咨询
- 公司业务查询
- 海外留学政策查询
- 课程与项目推荐
- 活动与讲座报名
- 常见问题自助解答
- 日常闲聊互动

### 3.2 核心流程

1. 用户输入 → 2. 多意图识别 → 3. 场景路由 → 4. 知识库检索/RAG → 5. 回答生成 → 6. 活动报名闭环

### 3.3 关键技术点

- 知识库与数据源搭建：基础文件解析、FAQ库、活动与课程数据库
- AI能力与提示词配置：多意图识别、年轻化闲聊人设、个性化推荐逻辑
- 核心交互与业务闭环：RAG精准问答、活动报名闭环

### 3.4 依赖关系

- 依赖《公司信息》、《公司业务》、《留学政策》三份核心文档
- 依赖历史高频咨询记录
- 依赖活动与课程数据库

---

## 四、企业智能助手模块开发设计

### 4.1 模块职责

- 意向客户录入、查询、状态更新
- 口述日报、管理日报查阅
- 组织架构查询
- 新人入职指引
- 学生业务综管

### 4.2 核心流程

1. 员工语音/文字输入 → 2. NL2SQL/指令解析 → 3. 数据表操作 → 4. 结果反馈

### 4.3 关键技术点

- 核心数据表与CRUD接口设计
- NL2SQL开发
- 新人指南知识库（QA + RAG）
- 主动待办推送
- 指令式业务处理

### 4.4 依赖关系

- 依赖意向客户表、员工日报表、投诉反馈表、学生成绩表
- 依赖新人指南、公司规章制度、业务流程文档

---

## 五、学生智能助手模块开发设计

### 5.1 模块职责

- 行政服务
- 心理关怀
- 售后反馈
- 学业考务
- 进度追踪
- 生活支持
- 增值转化

### 5.2 核心流程

1. 学生输入 → 2. 多意图路由 → 3. 业务处理 → 4. 数据表写入/查询 → 5. 结果反馈

### 5.3 关键技术点

- 核心数据表设计
- 业务逻辑开发：多意图路由、审批闭环、系统对接、知识库搭建
- AI能力配置：风险识别、智能摘要、营销生成

### 5.4 依赖关系

- 依赖学生行政服务表、心理健康画像表、心理预警表、售后反馈工单表
- 依赖教务系统、CRM系统
- 依赖海外生活指南、升学项目资料

---

## 六、智能报告模块开发设计

### 6.1 模块职责

- 全域客户经营分析报告
- 员工日报汇总报告（日/周）
- 学生心理健康周报
- 投诉处理周报

### 6.2 核心流程

1. 数据采集 → 2. AI智能汇总与分析 → 3. 报告生成 → 4. 报告输出

### 6.3 关键技术点

- 客户特征聚类与智能归因
- 日报核心进展、关键产出、潜在风险提取
- 心理态势汇总与风险群体识别
- 投诉智能分类、时效分析与预警

### 6.4 依赖关系

- 依赖客户数据、员工日报数据、学生心理数据、投诉数据
- 依赖定时任务调度

## 七、非功能设计

| 类别   | 设计说明                    |
| :--- | :---------------------- |
| 性能   | 常见问题秒级回复，查询与更新快速响应      |
| 可用性  | 7×24小时在线服务              |
| 安全性  | 客户信息、员工信息、学生心理数据安全存储与传输 |
| 可扩展性 | 数据表、知识库、报告类型支持后续扩展      |
| 可维护性 | 研判规则、Prompt、知识库支持更新与维护  |
