# 项目目录架构：最终汇总

项目根目录：`D:\AI\StuProject`。来源：`业务文档/09杂谈/马睿智/操作文档.md`第七章及已合并的相关配置、职责说明。整理日期：2026-10-17。

本文件将主文档多版公共／客服／研判／报告／企业／学生目录合成一棵树，按此前已确定的“保留技术分层、每层按业务模块分包”归位。沿用已给出的完整文件名方案补齐包初始化、页面资源和配套文件名；新增职责落到既有业务承载，不另建重复框架。

common为公共，agent为客服，customer为客户研判，report为报告，enterprise为企业，student为学生。`app/`下保留api、core、schemas、services、repositories、models、clients、tasks分层；main.py、config.py、database.py、access_control.yaml仍是唯一公共入口。app同级配置、Dify资产、前端、脚本、SQL、测试与文档均列出。

标注“存在”仅指提取时路径存在，不表示功能实现或联调通过；“规划”是后续交付目标。历史兼容及备份资产仅作参考，不自动部署。建议测试文件名沿用此前方案，实际开发时编写；业务文档、Git、日志及运行目录只列与架构相关范围，不逐条枚举其历史／运行内容。
